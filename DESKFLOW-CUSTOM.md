# Deskflow Custom

Это персональная сборка Deskflow на базе официального проекта Deskflow.

## Добавлено

- Глобальные медиаклавиши F6 / F7 / F8 с выбором маршрута: активный компьютер, конкретный компьютер или все компьютеры.
- Передача файлов через буфер обмена и перетаскивание через границу экрана.
- Передача файлов между Windows и Linux X11. Для Linux используется системный MIME-тип text/uri-list, отдельно от текста и изображений. На Wayland файловый URI clipboard пока не реализован: там сохраняются штатные текстовые и графические форматы.
- Тёмная тема для Linux и светлый интерфейс с нативным стилем Windows.
- Потоковая передача файлов с подтверждением блоков, проверкой путей и настраиваемым ограничением размера.

## Совместимость

Функции передачи файлов используют расширенный протокол Hopflow 1.100. Обе стороны соединения должны использовать Deskflow Custom с поддержкой этого протокола. Обычный Deskflow 1.27.0 не принимает эти пакеты.

Linux drag-and-drop реализован для X11. Полноценное перетаскивание между произвольными окнами Wayland пока не поддерживается.

При получении перетащенные файлы сохраняются в папку загрузок принимающего компьютера, затем Deskflow показывает уведомление и открывает эту папку. Перетаскивание не имитирует произвольный drop непосредственно внутрь окна стороннего приложения. Linux Flatpak получает доступ к домашнему каталогу только для чтения, а к Downloads - для записи. Это позволяет брать источники из домашней папки и сохранять полученные файлы без RW-доступа ко всему профилю.

## Совместимость настроек

Сохраняются штатные имена приложения, идентификаторы, расположения настроек, сертификаты и формат пользовательской конфигурации Deskflow. Это необходимо для обновления существующей установки без потери доверенных сертификатов и подключённых компьютеров.

Внешний deskflow-server.conf не удаляется при переходе на встроенную конфигурацию.

## Сборка

Windows MSI, Linux-пакеты и Flatpak собираются в GitHub Actions. Локальная установка компиляторов, Qt SDK и CMake на пользовательские компьютеры не требуется.
