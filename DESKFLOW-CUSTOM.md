# Deskflow Personal

Форк Deskflow с дополнительными функциями для работы между Windows и Linux.

## Функции

- Передача файлов через clipboard и drag-and-drop между компьютерами.
- Потоковая передача с manifest, чанками, подтверждениями и ограничением объёма неподтверждённых данных.
- F6 - предыдущий трек, F7 - воспроизведение/пауза, F8 - следующий трек. Для каждой клавиши можно выбрать активный компьютер, конкретный компьютер или все компьютеры.
- Русская локализация.
- Windows: темы System, Light и Dark.
- Linux: тёмная тема Fusion и изменяемый размер главного окна.
- Windows: необязательный Game Mode, удерживающий курсор на текущем компьютере во время полноэкранной игры.

## Передача файлов

Файловый обмен использует Hopflow 1.100. Обе стороны соединения должны работать на сборке Deskflow Personal с этим протоколом.

На Windows и Linux X11 полученные файлы могут передаваться в приложение под курсором через системный drag-and-drop. Принимающая сторона подготавливает временные файлы в пользовательском кэше. Они удаляются после завершения или отмены передачи.

Нативный drop возможен, если файлы успели загрузиться до отпускания кнопки мыши. Если передача ещё идёт, когда пользователь отпускает кнопку, drop не выполняется.

В Linux файловый обмен рассчитан на X11. Для Wayland файловый URI clipboard и нативный drag-and-drop не реализованы. Стандартная синхронизация текста и изображений работает отдельно.

## Совместимость и настройки

Сохранены штатные идентификаторы приложения, MSI upgrade identity, расположения конфигурации, формат настроек и TLS-идентичность. Обновление не требует пересоздания доверенных сертификатов и списка компьютеров.

Внешний `deskflow-server.conf` сохраняется при переходе на встроенную конфигурацию.

## Сборка

GitHub Actions собирает Windows x64 MSI, Linux x86_64 с unit-тестами и Linux x86_64 Flatpak. Установщики публикуются в GitHub Releases.
