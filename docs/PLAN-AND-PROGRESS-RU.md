# Deskflow Personal - состояние проекта

Последнее обновление: 25 ноября 2026 года.
Рабочая ветка: `work/file-transfer`.
Основная ветка: `master`.

## Реализовано

- Файловый транспорт Hopflow 1.100 с потоковой передачей, manifest, подтверждениями и ограничением очереди.
- Передача файлов через clipboard.
- Нативный drag-and-drop между Windows и Linux X11.
- Медиаклавиши F6/F7/F8 с настройкой получателей.
- Русская локализация в установочных пакетах.
- Windows: темы System/Light/Dark и Game Mode.
- Linux: тёмная тема и свободное изменение размера окна.
- Сохранение существующей конфигурации Deskflow и TLS-идентичности.
- Сборка Windows MSI, Linux и Flatpak через GitHub Actions.

## Ограничения

- Файловый обмен и нативный drag-and-drop в Linux поддерживаются для X11. Wayland пока не поддерживается для этих сценариев.
- Перед отпусканием кнопки мыши файлы должны успеть загрузиться на принимающий компьютер. Иначе drop отменяется.
- Game Mode доступен в Windows и выключен по умолчанию.
- Перетаскивание в сторонние приложения, поведение в полноэкранных играх и задержка мыши требуют проверки на двух устройствах.
